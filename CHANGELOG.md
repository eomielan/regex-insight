# Change Log

All notable changes to the "regex-insight" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2024-10-26

### Added

- Initial release with regex highlighting in JavaScript and TypeScript files.
- Hover provider to display example matches for regex patterns.
- Configuration options for enabling/disabling and setting highlight color.
- Document and editor listeners to update highlights in real-time.
